# Your Name — portfolio template

A responsive HTML, CSS, and TypeScript portfolio with a playful paper-and-grid look. The content is intentionally sample copy: swap in your own name, biography, links, skills, photos, and projects.

## Get started

1. Install [Node.js](https://nodejs.org/).
2. Run `npm install`.
3. Run `npm run build` to compile `main.ts` into `main.js`.
4. Open `index.html` in a browser, or serve this folder with your preferred static web server.

After editing `main.ts`, run `npm run build` again. The project cards, dates, colors, descriptions, images, and links are all in the `projects` array near the top of that file. Replace the sample portrait and workspace image URLs in `index.html`, and update the placeholder contact and social links there too. No framework is required.
